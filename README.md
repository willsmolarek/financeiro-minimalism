# Dashboard Financeiro Pessoal — Minimalista

Aplicação web minimalista para gerenciamento de finanças pessoais e simulação de crescimento patrimonial a longo prazo, construída com Python, Streamlit, Pandas e Plotly. Os dados são armazenados localmente no navegador do usuário utilizando LocalStorage.

## Funcionalidades

- Registro de transações (Receitas e Despesas).
- Armazenamento local no navegador via `streamlit-local-storage` (sem necessidade de banco de dados externo).
- Métricas e KPIs (Recebimentos, Gastos e Saldo) com filtros por período (Hoje, Mês Atual, Ano Atual, Total).
- Gerenciamento e edição de histórico de lançamentos diretamente na interface.
- Simulador de projeção patrimonial baseado em aportes mensais e juros compostos com gráfico interativo.
- Interface customizada com CSS e suporte a layout responsivo para dispositivos móveis.

## Tecnologias Utilizadas

- Python
- Streamlit
- Pandas
- Plotly
- Streamlit LocalStorage
