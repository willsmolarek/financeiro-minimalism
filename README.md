Dashboard Financeiro Pessoal — Minimalista
Aplicação web para gerenciamento de finanças pessoais, controle multiusuário e simulação de crescimento patrimonial a longo prazo. O projeto foi desenvolvido em Python utilizando Streamlit, Pandas, Plotly e integração com banco de dados em nuvem MongoDB Atlas.

 Funcionalidades
Autenticação e Segurança: Sistema de login e cadastro de usuários com criptografia de senhas via bcrypt e gerenciamento de sessão por usuário.

Persistência de Dados em Nuvem: Todos os lançamentos são sincronizados no MongoDB Atlas, permitindo acesso de qualquer dispositivo.

Registro de Transações: Cadastro ágil de receitas e despesas com categorização e datas.

Métricas e KPIs: Visualização rápida do total de recebimentos, gastos e saldo, com filtros temporais (Hoje, Mês Atual, Ano Atual e Total).

Gestão e Edição em Tabela: Tabela interativa para edição dinâmica de registros e remoção simplificada de lançamentos em lote.

Simulador Patrimonial: Gráfico interativo com projeções de juros compostos a longo prazo baseadas em aportes mensais customizáveis.

Design Minimalista & Responsivo: Interface limpa, estilizada com CSS customizado e adaptada para telas móveis e desktop.

 Tecnologias Utilizadas
Linguagem: Python

Interface & Dashboard: Streamlit

Manipulação de Dados: Pandas

Gráficos Interativos: Plotly

Banco de Dados: MongoDB Atlas (pymongo)

Segurança: Bcrypt (hash de senhas)
